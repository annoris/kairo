# Cómo Contribuir y Desbloquear Acceso al Repositorio Privado (`annoris/kairo-pro`)

¡Gracias por tu interés en **KAIRO**!

Este repositorio público ([`annoris/kairo`](https://github.com/annoris/kairo)) comparte la documentación completa, el GIF showcase, los principios de arquitectura y la carpeta visual [`kairo/`](./kairo/). El **código fuente completo descargable** (Next.js 14 + Three.js/R3F + Shaders GLSL + Navier-Stokes Fluid + GSAP/Lenis) se encuentra en el **repositorio privado [`annoris/kairo-pro`](https://github.com/annoris/kairo-pro)** y está reservado exclusivamente para **contribuidores aprobados**.

---

## 🔑 Cómo Obtener Invitación a `annoris/kairo-pro`

Para recibir una invitación directa al repositorio privado [`annoris/kairo-pro`](https://github.com/annoris/kairo-pro) en GitHub, completa **una** de las siguientes vías de contribución:

### Opción 1 — Pull Request de Valor en `annoris/kairo`
Envía un Pull Request en [`https://github.com/annoris/kairo`](https://github.com/annoris/kairo) que aporte mejoras reales a la comunidad:
- Mejoras, diagramas o explicaciones profundas en `ARCHITECTURE.md` o `README.md`.
- Guías técnicas complementarias (por ejemplo: optimización de shaders GLSL, accesibilidad en WebGL, o benchmarks de rendimiento).
- Traducciones completas y cuidadas de la documentación (inglés, francés, alemán, portugués, japonés, etc.).

### Opción 2 — Issue Técnico / Auditoría de Diseño
Abre un Issue bien estructurado en [`https://github.com/annoris/kairo/issues`](https://github.com/annoris/kairo/issues) con:
- Propuestas detalladas de arquitectura, performance, UX o accesibilidad.
- Casos de estudio o ideas de nuevas escenas 3D/shaders que encajen con la estética **Dark Luxury** de KAIRO.

### Opción 3 — Colaboración Directa o Patrocinio
Si deseas colaborar como Creative Technologist, diseñador 3D o patrocinar el proyecto, escríbenos directamente indicando tu perfil de GitHub:
- **Email:** `hello@kairo.studio`
- **Asunto:** `[KAIRO-PRO Access] Colaboración — @tu-usuario`

## 📋 Proceso Paso a Paso (Pull Requests)

1. **Haz Fork** de [`annoris/kairo`](https://github.com/annoris/kairo).
2. **Crea una rama descriptiva**:
   ```bash
   git checkout -b docs/mejora-arquitectura-shaders
   ```
3. **Realiza tus cambios** cuidando claridad, ortografía y formato Markdown limpio.
4. **Abre un Pull Request** en `annoris/kairo` explicando qué aporta tu contribución y deja visible tu usuario de GitHub.
5. **Revisión y Acceso**: Una vez que tu PR sea revisado y aceptado (*merged*), recibirás una **invitación oficial de colaborador al repositorio privado [`annoris/kairo-pro`](https://github.com/annoris/kairo-pro)** directamente en tu cuenta de GitHub.

---

## 📜 Reglas de Uso del Código Privado

Al recibir acceso al repositorio privado, te comprometes a:
- No redistribuir, revender ni republicar el código fuente completo de forma pública.
- Utilizar el código para aprendizaje, inspiración o proyectos autorizados respetando los créditos correspondientes.
